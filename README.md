# viteme-web

Frontend do **Viteme**: site que centraliza a divulgação, a inscrição e o acompanhamento dos eventos da faculdade, com avisos de alteração e sem taxa da plataforma.

SPA em **React + TypeScript (Vite)** que consome a API REST em [`SeuDemar/viteme-api`](https://github.com/SeuDemar/viteme-api) (ASP.NET Core, `/api/v1`).

> **Estado:** em planejamento. A documentação está em [`.claude/planning/`](.claude/planning/README.md); o código ainda não foi iniciado.
